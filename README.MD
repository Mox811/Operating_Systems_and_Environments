ДЗ 8. Функции в Bash
Задание: ответить, чем exit отличается от return, и написать функции: вывод текста в выбранный поток (stdout, stderr, файл); вывод сведений о системе по параметру (pwd, user, version и т. д.); вывод значения переменной по имени через eval в цикле до Ctrl + D.

В работе: функция вывода сообщения в стандартный поток, в поток ошибок (ERROR: …) и с дозаписью в файл (>>); скрипт, который по параметру выводит рабочую директорию, имя пользователя ($USER) или версию Bash ($BASH_VERSION); функция show_value, которая через eval выводит значение переменной по введённому имени и завершает цикл по Ctrl + D
