# ДЗ 4. Администрирование

**Задание:** команды для работы с процессами: вывести дерево процессов, процессы не от своего пользователя, пять процессов с наибольшим потреблением памяти, фоновые процессы.

**В работе:** `ps -ejH`, `ps -ef | grep -v root`, `ps aux --sort=-rss | head -n 6`, `ps -ej | grep -v tty` со скриншотами.
