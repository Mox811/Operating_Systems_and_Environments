# ДЗ 2. Простые команды

**Задание:** практика команд `cd`, `ls`, `cat`, `grep`, `find`: показать `.log`-файлы в `/var/log`, отсортировать `/usr/bin` по размеру, вывести `/etc/apt/sources.list`, найти строки с `root` в `/etc/passwd`, вывести `/etc/services` без комментариев, искать файлы в `/etc`, `/usr/share`, `/var` по имени, типу, глубине и владельцу, использовать `find -exec grep`.
