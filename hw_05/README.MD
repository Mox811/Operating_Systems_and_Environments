ДЗ 5. Администрирование 2: возвращение сети
Задание: подключить к ВМ второй адаптер VirtualBox Host-Only, разобрать вывод ip address, назначить адаптеру адрес из сети 192.168.56.0 командой ip address add и проверить связь ping: с самим собой, с хостом и с хоста на гостевую машину.

В работе: просмотр адаптеров через ip address; включение адаптера enp0s8 (ip link set enp0s8 up) и назначение ему адреса 192.168.56.10/24; проверка связи ping; просмотр сетевых настроек хост-машины через ipconfig в командной строке Windows.
