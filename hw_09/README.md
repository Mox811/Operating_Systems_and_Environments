# ДЗ 9. Автоматизация компиляции: Unix Makefiles

**Задание:** автоматизировать сборку программы на GNU Assembler с помощью Unix Makefiles.

**В работе:** установка `binutils` и `make`, программа `main.s` (выход через системный вызов 60), Makefile с целями сборки и очистки, проверка `make build`.
