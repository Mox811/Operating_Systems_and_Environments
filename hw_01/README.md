# ДЗ 1. Создание снимков виртуальной машины

**Задание:** сделать снимок ВМ в VirtualBox, «сломать» систему патчем Бармина (`rm -rf --no-preserve-root /`), убедиться, что ОС больше не загружается, и восстановить её из снимка.

**В работе:** объяснение, почему ВМ не загружается: повреждён загрузчик GRUB, отсутствует файл `/boot/grub/i386-pc/normal.mod`, поэтому система не может запустить ядро.
